# かまくらランタンフェス 南会津 2027 / 静的プレビュー版

この `public/` フォルダー内のファイルをまとめて静的ホスティングに配置してください。
WordPress本番への追加は `aizu-kamakura-2027-plugin.zip` をご利用ください。既存テーマは変更しません。

- かまくら体験：予約受付準備中。予約URLは SELECTTYPE（設定に保持）
- コテージ宿泊：AirHost（公開リンク）
- 画像と動画：演出用のイメージです。実際の会場写真とは限りません。
- かまくら照明：内側に灯る光のイメージのみ。竹製ランタンの設置は表示していません。
- SEO：GitHubサンプルは robots.txt でインデックスを制限しています。
